## 🤖 Claude 사용 방법

### 매월 데이터 업데이트

1. **삼성카드 내역 다운로드**
   - samsung.com → 마이페이지 → 이용내역 → 엑셀 다운로드
   - 파일명: `삼성카드_YYYYMM.xlsx` 로 저장

2. **우리은행 내역 다운로드**
   - 우리은행 앱 또는 인터넷뱅킹 → 거래내역 → 다운로드
   - 파일명: `우리은행_YYYYMM.xlsx` 로 저장

3. **data/연도 폴더에 파일 이동**

4. **Claude에게 분석 요청**
   ```
   "2026년 NN월 가계부 분석해줘"
   ```

### Claude가 자동으로 하는 것
- `rules/categories.md` 기준으로 거래내역 카테고리 분류
- 고정지출 자동 식별
- 월별 리포트 생성 → `reports/` 폴더 저장
- 이상 지출 감지 및 알림
