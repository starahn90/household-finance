## 분류 규칙 우선순위

1. **애매한 가맹점 목록** 에 있으면 해당 분류 적용
2. **가맹점명 키워드** 기반 자동 분류 (위 카테고리 목록 참고)
3. **금액 패턴**: 매월 동일 금액이면 구독/고정지출 의심
4. **판단 불가** 시: `기타` 카테고리로 분류하고 비고에 원본 가맹점명 기록

## 분류 시 주의사항

- 쿠팡: 금액이 크면 생활용품, 소액이면 식료품일 가능성 높음
- 백화점 계열: 카드사 공용 가맹점명인 경우 내역 상세 확인 필요
- 해외결제: USD/EUR 등 외화 표시 시 여행 또는 구독서비스 확인
